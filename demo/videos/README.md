# Reviewed demonstration videos

These are the three original WhatsApp recordings explicitly selected by the uploader for the project. The two action clips are staged reenactments. Descriptions and action labels are reviewed metadata, not claims that the models independently detected every action.

- [Quiet scene](quiet-scene.mp4): original `20.08.50`; ordinary activity, no concerning action.
- [Staged contact and fall](staged-contact-and-fall.mp4): original `20.09.51`; a strike followed by a fall.
- [Staged jacket taking](staged-jacket-taking.mp4): original `20.10.46`; jacket removal followed by running away.

[manifest.json](manifest.json) records the original filenames, reviewed descriptions/tags, exact SHA-256 values, and file sizes. The MP4 files are byte-identical to the uploads; no generated review copy replaces an original.

The public campus activity snapshot is separate: [public-data/activity](../../public-data/activity/README.md). Model adapters are versioned separately in the private Hugging Face registry.
