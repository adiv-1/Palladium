# Palladium brand

The helmet and crest come from the team's `feature/palladium-ui-polish` design.
`mark.svg` is the navigation mark; `shield.svg` is the larger login treatment.
The React component lives in `apps/web/src/Logo.tsx`; the favicon is bundled from
`apps/web/src/brand/favicon.svg`.

Shared interface tokens live in `apps/web/src/theme.css`: graphite surfaces,
off-white controls and typography, and restrained red/gold logo accents.
Operational identifiers, configuration keys and authentication cookies retain
their existing names for compatibility.
